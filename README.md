Student Management System

This is a Java project for managing student records. It allows student information 
to be added, viewed, updated and deleted through a simple student management system.

The project was built to practise Java programming and organising a program into 
separate layers rather than keeping everything in one class.

Features
* Add new students
* View student records
* Update existing student details
* Delete students
* Input validation
* Saves student data using JSON
* Organised using a layered structure

Technologies Used

* Java
* JSON
* IntelliJ IDEA

Project Structure

The project is split into different classes to keep the code organised 
and make it easier to maintain.

The main source code can be found in:
src/studentmanagement

Running the Project:
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure Java is installed and configured.
4. Run the main class to start the program.

I created this project to improve my understanding of Java, CRUD operations, 
file/data persistence, validation and structuring a larger program across multiple classes.
